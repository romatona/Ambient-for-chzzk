# chizAmbi

치지직(CHZZK) 라이브 영상의 색을 화면 주변으로 퍼뜨리는 앰비언트 조명 확장 프로그램입니다. 이름은 **치지직 + Ambient**에서 가져왔습니다.

**현재 버전: 0.1.17 · 개발 중인 프로토타입**  
Microsoft Edge를 주 테스트 환경으로 개발한 Chromium Manifest V3 확장입니다. Chrome에서도 압축 해제 방식으로 설치할 수 있으나, 모든 환경에서의 동작을 검증한 것은 아닙니다.

## 주요 기능

- 영상 크기와 위치를 유지하면서 페이지 뒤에 앰비언트 조명을 표시합니다.
- 헤더·사이드바·채팅 및 랭킹 영역의 배경을 조정하고, 제목과 입력창의 가독성을 보정합니다. 채팅 닉네임의 개별 색상은 유지합니다.
- 확장 아이콘의 팝업에서 방향·밝기·흐림·퍼짐·페이드인 등을 설정합니다.
- 두 개의 기본 프리셋과 저장 가능한 유저 프리셋을 제공합니다.
- **G 키** 또는 **재생 도구바의 소나 아이콘**으로 조명을 켜고 끕니다.
- WebGL을 우선 사용하고, 초기화 또는 렌더링 실패 시 Canvas 2D로 전환을 시도합니다.

상시 플로팅 설정창은 없습니다. 재생 도구바 버튼은 조명 ON/OFF만 담당하며, 상세 설정은 확장 팝업에서 변경합니다.

## 설치

### 1. 설치 파일 준비

이미 빌드된 파일이 있다면 `manifest.json`이 들어 있는 `dist` 폴더를 사용합니다.

GitHub 등에서 **소스만 받은 경우에는 먼저 빌드**해야 합니다. `dist`는 `.gitignore`에 포함되어 있으므로 소스 다운로드에 포함되지 않을 수 있습니다.

Node.js **22 이상**과 npm이 설치된 환경에서 프로젝트 폴더를 열고 실행합니다.

```sh
npm ci
npm run build
```

### 2. Edge에 로드

1. 주소창에 `edge://extensions`를 입력합니다.
2. **개발자 모드**를 켭니다.
3. **압축 풀린 파일 로드**를 누릅니다.
4. 프로젝트 루트가 아니라 **`dist` 폴더**를 선택합니다.
5. 열려 있는 치지직 방송 탭을 새로고침합니다.
6. 브라우저의 확장 메뉴에서 chizAmbi를 도구 모음에 고정하면 설정에 쉽게 접근할 수 있습니다.

Chrome은 `chrome://extensions`에서 같은 방식으로 설치합니다. 원격 디버깅 포트나 실행 중인 개발 서버는 필요하지 않습니다.

> 현재는 로컬 설치 방식입니다. GitHub에서 파일을 받더라도 개발자 모드가 필요하며, 브라우저의 개발자 모드 안내를 없애는 방식은 아닙니다.

### 업데이트

1. 변경된 소스에서 `npm run build`를 실행합니다.
2. 확장 관리 화면에서 chizAmbi의 **다시 로드**를 누릅니다.
3. 치지직 방송 탭도 새로고침합니다.

같은 확장을 다시 로드하면 저장한 설정과 유저 프리셋을 유지할 수 있습니다. 확장을 제거하면 로컬 설정이 삭제될 수 있습니다.

## 사용 방법

### 조명 켜기·끄기

다음 세 가지 방법은 같은 ON/OFF 설정을 사용합니다.

- 확장 팝업 맨 위의 스위치
- 치지직 라이브 페이지에서 **G 키**
- 재생 도구바 오른쪽 버튼 그룹 맨 앞의 **소나 아이콘**

소나 아이콘은 흰색을 유지하며, 우측 하단의 **초록 점은 ON**, **회색 점은 OFF**를 나타냅니다. 마우스를 올리면 **영화모드 (G)** 툴팁이 표시됩니다. 여기서 영화모드는 앰비언트 조명 ON/OFF를 뜻하며, 치지직의 넓은 화면 모드를 변경하지 않습니다.

G 키는 채팅·검색창 등 입력 요소에 포커스가 있거나 한글 조합 중일 때 작동하지 않습니다. Ctrl·Alt·Shift·Meta 조합과 키를 길게 눌러 생기는 반복 입력도 무시합니다.

### 프리셋

| 프리셋 | 밝기 | 흐림 | 퍼짐 |
| --- | ---: | ---: | ---: |
| 프리셋 1 | 100% | 30% | 17% |
| 프리셋 2 | 110% | 10% | 100% |
| 유저 프리셋 1 | 사용자가 저장한 값 | 사용자가 저장한 값 | 사용자가 저장한 값 |

원하는 값으로 조절한 뒤 **현재 값 저장**을 누르면 유저 프리셋 1에 저장됩니다. 다시 저장하면 기존 값을 덮어씁니다. 저장 전에는 유저 프리셋 적용 버튼이 비활성화됩니다.

프리셋은 **밝기·흐림·퍼짐 세 값만** 저장·적용합니다. 조명 ON/OFF, 방향, 페이드인, 테마, WebGL 설정은 바꾸지 않습니다.

### 상세 설정

| 설정 | 범위 / 선택지 | 초기값 |
| --- | --- | --- |
| 조명 방향 | 위·오른쪽·아래·왼쪽 개별 ON/OFF | 모두 ON |
| 밝기 | 0~200% | 100% |
| 흐림 | 0~100% | 30% |
| 퍼짐 | 1~100% | 17% |
| 페이드인 시간 | 꺼짐~5초 | 꺼짐 |
| 설정창 테마 | 밝게·시스템·어둡게 | 어둡게 |
| WebGL 사용 | ON/OFF | ON |

**각 조절바를 더블클릭하면 해당 항목만 초기값으로 복원**합니다. 유저 프리셋의 저장값은 변경되지 않습니다. 설정창 테마는 확장 팝업의 테마이며, 치지직 사이트 자체의 테마 선택 기능은 아닙니다.

설정은 브라우저 프로필의 확장 로컬 저장소에 보관되며, 같은 프로필의 열린 치지직 라이브 탭들에 공유됩니다. 다른 PC로 자동 동기화되지는 않습니다.

## 지원 범위와 제한

- 현재 조명 대상은 `https://chzzk.naver.com/live/채널ID` 형태의 **라이브 페이지**입니다. 다시보기·클립·YouTube는 대상이 아닙니다.
- 숨겨진 탭, Fullscreen API를 사용하는 전체 화면, PiP 상태에서는 조명을 일시 중단합니다. 창 최대화나 페이지 내 넓은 화면과는 구분됩니다.
- 스크롤 등으로 영상이 헤더 뒤에 가려지거나 화면 밖으로 잘리면 조명을 중단할 수 있습니다. 조건이 복구되면 다시 표시합니다.
- 영상 요소가 교체되면 다시 연결하고, 표시 위치와 크기를 주기적으로 반영합니다.
- 일반적인 `contain`/`scale-down` 배치의 검은 여백을 고려해 실제 영상 영역을 계산합니다. **영상 자체에 포함된 검은 띠를 분석해서 제거하는 기능은 없습니다.**
- 다른 확장이 영상을 확대·이동·자르거나 미니 플레이어로 바꾸면 조명 경계가 어긋나거나 중단될 수 있습니다. 모든 병용 조합을 보장하지 않습니다.
- 치지직이 페이지 구조나 클래스 이름을 바꾸면 도구바 버튼·배경 보정 등에 수정이 필요할 수 있습니다.
- 원본 확장의 전체 설정, HDR 최적화, 검은 띠 자동 감지 등은 포함하지 않습니다.

## 문제 해결

| 증상 | 확인할 사항 |
| --- | --- |
| 매니페스트 파일이 없다는 설치 오류 | 빌드 후 `dist/manifest.json`이 있는지 확인하고, 루트 대신 `dist`를 선택합니다. |
| 업데이트가 보이지 않음 | 확장 다시 로드와 방송 탭 새로고침을 모두 진행합니다. |
| 조명이 보이지 않음 | 라이브 페이지인지, ON 상태인지, 밝기가 0인지, 영상이 가려지거나 전체 화면·PiP 상태인지 확인합니다. |
| G 키가 반응하지 않음 | 채팅·검색창에서 포커스를 빼고 G만 누릅니다. |
| 그래픽 오류 또는 조명 깨짐 | 팝업에서 WebGL을 끄고 Canvas 2D 경로로 확인합니다. |
| 특정 패널에 검은 배경이 남음 | 해당 방송과 패널의 접힘/펼침 상태를 함께 기록합니다. 사이트 구조별 추가 대응이 필요할 수 있습니다. |

## 개발

```sh
npm ci
npm test
npm run build
```

- `npm test`: 설정 검증, 프리셋·단축키 예외, 영상 경계 계산, 페이지 복원, 렌더러 정리 등의 Node.js 테스트
- `npm run build`: Rollup 번들링 → Sass 컴파일 → 매니페스트·팝업·아이콘·라이선스 패키징
- `npm run demo`: `http://127.0.0.1:4173/live/demo`에서 생성 영상 기반 렌더러 데모 실행. 먼저 빌드가 필요합니다.

데모는 실제 방송이나 확장 설치 환경을 대체하지 않습니다. 별도의 로컬 저장소를 사용하며, 실제 치지직 도구바·팝업·설정 변경 전파까지 검증하는 환경은 아닙니다.

### 주요 파일

```text
src/
  popup.html                    확장 설정 팝업
  scripts/chizambi/
    controller.js               영상 연결·조명 수명주기·단축키
    model.js                    기본값·설정 검증·영상 경계 계산
    page-theme.js               페이지 배경 적용·복원
    popup.js                    설정·프리셋 UI
    presets.js                  프리셋 값·단축키 입력 예외
    toolbar.js                  재생 도구바 버튼
    toolbar-icon.js             도구바용 내장 아이콘 데이터
    storage.js                  확장 로컬 저장소
  scripts/libs/                 원본에서 가져온 렌더러와 유틸리티
  styles/                       콘텐츠·팝업 스타일
  images/                       확장 아이콘과 디자인 원본
scripts/package.mjs             설치용 파일 패키징
scripts/demo-server.mjs         로컬 렌더러 데모 서버
tests/                          자동 테스트
dist/                           빌드 결과·확장 설치 대상
```

`package.json`의 버전이 빌드 시 `dist/manifest.json`에 반영됩니다. 도구바 아이콘은 `toolbar-icon.js`에 내장되어 있으므로 확장 아이콘 PNG만 교체해도 자동으로 바뀌지는 않습니다.

개발용 캡처와 과거 검증 기록은 공개 패키지에서 제외했습니다. 자동 테스트와 빌드 성공만으로 모든 실제 방송·브라우저 조합이 검증된 것은 아닙니다.

## 권한과 데이터 처리

- 확장 권한: `storage`
- 콘텐츠 스크립트 삽입 대상: `https://chzzk.naver.com/*`
- 영상 프레임은 브라우저 안에서 조명 렌더링에 사용합니다.
- 설정과 유저 프리셋은 `chrome.storage.local`에 저장합니다.
- 현재 활성 확장 코드에는 분석·추적 전송이나 별도 서버로의 영상 업로드 기능이 없습니다.
- 원본 영상의 주소, `crossOrigin`, 재생 위치, 재생/일시정지 상태를 변경하지 않습니다.
